## 原理解析（硬件说明）
本项目由 主控与下载、惯性测量（IMU）、动力与驱动、电源与检测、无线与地面站 等部分组成。

1. 主控与下载
核心为 ESP32-S3-WROOM-1，负责读 IMU、控制电机 PWM、开 WiFi 热点、与网页地面站通信。
EN 经 10kΩ 上拉到 3.3V，板载 BOOT（IO0） 按键；串口排针引出 TXD0 / RXD0 / 3.3V / GND。
因 未做自动下载电路（EN 无法被 USB 转串口自动拉低），烧录时需：断电 → 按住 BOOT → 上电 → 再烧录。
与 CH340 等 USB 转串口连接时，注意 TX/RX 交叉 与 共地。
2. 惯性传感器（BMI270）
BMI270 通过 I2C 与主控相连：SDA=GPIO18，SCL=GPIO8，地址 0x68，芯片 ID 0x24。
CSB 上拉为 I2C 模式；SDA/SCL 有 4.7kΩ 上拉。
固件用乐鑫 espressif/bmi270 组件读取加速度与角速度；安装在板中央时振动较大，需结合软件滤波。
IMU 若贴装在机板「底层」/轴向与机身定义不一致，需在软件中做 轴符号修正（以实机拧动方向为准）。
3. 动力与电机驱动
四路 有刷空心杯 经 H 桥（如 DRV8833） 驱动；主控以 LEDC PWM 控制 IN1/IN2 实现正反转与调速。

偏航（拧机）主要靠 对角电机差动（如 M2+M4 与 M1+M3）；俯仰为前后两对；横滚为左右两对。
46mm 级别惯性小，离地数厘米内气流紊乱，不宜长时间贴地悬停。
4. 电源与检测
电机与逻辑共用单节锂电体系；GPIO19 经电阻分压采样电池电压。
电压偏低时推力下降、易「只嗡鸣不转」；调参与试飞前请保证电量充足。
部分自制板可能出现 电池焊盘与芯片供电路径不一致，需保证各路电机驱动的 VM 与 GND 可靠连接。

## 注意事项
烧录方式：EN 无自动复位，必须 BOOT + 重新上电 才能进下载模式。
串口接线：USB 转 TTL 与板载排针 TX/RX 交叉，并 共地；接线反了会出现「无串口数据」。
电机与混控：拧机、前后倾、左右倾时电机应按 对角/前后/左右 成组变化；若始终绑在一起，先查 IN1/IN2 是否短接、桨向与 DIR_INVERT。
电量：低电压下易异常、纠正力不足；请满电或充足电量后再调飞行。
振动与重量：IMU 靠近重心、结构尽量牢固；46mm 级别对振动与重心极其敏感。
目前缺陷：悬停、PID/自动稳定、抗风与续航均未完善，请自行评估风险后再改机试飞。
